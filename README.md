## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Tirhuta-Mithilakshar-Fonts-Archive/main/install.sh | bash
```

```powershell

```
